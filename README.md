# QuickShot

![QuickShot 图标](QuickShot-icon.png)

面向 Windows 10/11 的轻量截图工具，解决系统截图步骤繁琐、使用微信截图又需要额外启动应用的问题。按下快捷键即可框选内容，松开鼠标后自动复制，回到 ChatGPT 或其他应用直接粘贴。

## 核心功能

- `Alt + A` 全局快捷键唤起截图，冲突时自动切换至 `Ctrl + Shift + A`；
- 自由框选，松开鼠标后自动复制至剪贴板；
- `Esc` 随时取消截图；
- 托盘常驻，可切换自动保存、打开截图文件夹及设置开机启动；
- 专属应用图标与中文托盘菜单；
- 局部区域刷新，减少高分辨率屏幕下的框选卡顿；
- 首次启动后生成独立 `QuickShot.exe`，后续无需重复编译。

## 下载与使用

1. 在仓库中下载 `dist/QuickShot-Windows-v2.zip`，并解压整个 `QuickShot` 文件夹。
2. 双击 `启动截图工具.bat`。第一次启动会自动生成程序，并在桌面创建带图标的 `QuickShot` 快捷方式。
3. 以后直接双击桌面的 `QuickShot` 图标即可，不必再打开压缩包或批处理文件。
4. 按 `Alt + A`，拖动鼠标框选内容，松开鼠标后截图会自动复制。
5. 回到 ChatGPT，按 `Ctrl + V` 粘贴图片；按 `Esc` 可以取消截图。

如果 `Alt + A` 已经被其他程序占用，工具会自动改用 `Ctrl + Shift + A` 并弹出提示。


## 技术与协作方式

项目采用 PowerShell 与 C# WinForms 实现，通过 AI 协作完成需求拆解、程序搭建、问题定位与迭代优化。产品目标、交互逻辑、视觉方向和实际测试由项目发起者主导，AI 辅助生成与重构代码。

初版已经实现快捷键截图、剪贴板复制与托盘控制；后续根据试用中发现的默认图标、启动速度及拖动卡顿问题，增加专属图标、中文菜单和独立 EXE，并将全屏重复绘制改为局部区域刷新。

## 当前状态

目前为可运行的个人工具原型。项目文件和压缩包已经完成结构检查，但不同 Windows 屏幕缩放、多显示器组合及安全策略仍可能产生兼容性差异，欢迎通过 Issues 反馈。

## 关闭或卸载

右键右下角的 QuickShot 图标，选择“退出 QuickShot”即可关闭。若开启过开机启动，请先在菜单中取消勾选“开机自动启动”，然后删除桌面快捷方式和整个 QuickShot 文件夹即可。

## 从旧版更新

先右键旧版托盘图标并退出，然后解压这个新版到一个新的文件夹中，双击 `启动截图工具.bat`。确认新版可以截图后，就可以删除旧版文件夹。
